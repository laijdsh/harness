#### 本阶段遇到的问题与处理

1. **缺少 Jakarta Validation 依赖**
   - 问题：第一次构建时报 `jakarta.validation` 包不存在。
   - 处理：在 `pom.xml` 中增加 `spring-boot-starter-validation` 后构建通过。

2. **Spring Boot 4 / Jackson 3 配置不兼容**
   - 问题：配置 `spring.jackson.serialization.write-dates-as-timestamps=false` 后，
     启动时报 Jackson 3 没有该枚举值。
   - 原因：Spring Boot 4.1 默认使用 Jackson 3，配置项从 Jackson 2 迁移。
   - 处理：删除该配置；时间字段默认按 ISO-8601 字符串输出。

3. **Bootstrap CDN 被网络重置**
   - 问题：jsDelivr 下载 Bootstrap 时连接被重置。
   - 处理：从官方 npm registry 下载 Bootstrap 5.3.9 tarball，解压出 CSS/JS
     放到项目本地 `static/vendor/bootstrap/`，运行时不依赖 CDN。

4. **SQL 中文注释导致建表报错**
   - 问题：通过 PowerShell 管道把 UTF-8 SQL 传给 MySQL 客户端时，中文注释被按错误编码解析。
   - 处理：让 MySQL 客户端直接读取 UTF-8 SQL 文件，并指定
     `--default-character-set=utf8mb4`。

5. **PowerShell 变量拼接导致分页测试假失败**
   - 问题：`"$base?page=0"` 中 `$base?page` 被当成变量名，URL 变成 `=0&...`，
     分页/搜索测试返回 0。
   - 处理：改用 `"${base}?page=0"`；应用接口本身正常。

6. **页面 favicon 404**
   - 问题：浏览器控制台报 `/favicon.ico` 404。
   - 处理：增加 `favicon.svg` 并在页面 head 中声明。

7. **重定向 URL 出现 `;jsessionid`**
   - 问题：首次表单提交重定向时 URL 带 session id。
   - 处理：配置 `server.servlet.session.tracking-modes=cookie`。

#### 本阶段遇到的问题与处理

1. **响应时间解析为 null**
   - 问题：`127.0.0.1` 状态为 ONLINE，但 `responseTimeMs` 为空。
   - 原因：Java 进程中的 Windows ping 输出为中文“时间<1ms”，原正则只匹配英文 `time`。
   - 处理：正则同时匹配 `time`/`时间` 和 `ms`/`毫秒`，重新检测后解析为 0ms。

2. **详情页检测后没有成功提示**
   - 问题：列表页有 Flash 提示，详情页没有渲染 `successMessage`。
   - 处理：在详情页增加成功/失败提示区域，重新构建后验证通过。

3. **监测历史表外键/字段映射**
   - 问题：需要在不重建 `network_device` 的前提下增加字段和监测表。
   - 处理：编写 `sql/phase3-migration.sql` 做增量迁移，保留阶段 2 的 4 台设备数据，
     并让 JPA `validate` 在启动时验证新结构。

4. **Windows 控制台中文编码**
   - 现象：日志中中文在控制台/重定向文件中显示为乱码。
   - 结论：数据库和页面中文正常，属于控制台编码问题，不影响业务数据；
     日志截图时需要注意该现象。
